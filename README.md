# LoRaCpp — LoRa PHY на C++ (порт LoRaPHY)

Консольная программа на **C++17** для чтения сигнала из файла, **демодуляции** и
**декодирования** LoRa-пакетов. Это ручной модульный порт
[`LoRaPHY.m`](../LoRaPHY-master/LoRaPHY.m), сориентированный на пример
`examples/vsop2.m` (чтение `.pcm`, явный заголовок, режим без fast_mode).

Зависимостей нет: FFT произвольной длины, ресемплер, ФНЧ, Hamming, CRC и
арифметика GF(2) реализованы внутри. Есть и передающая часть (кодирование +
модуляция) для самопроверки round-trip.

> **Проверено:** вывод C++ **побитово совпадает** с оригинальным MATLAB
> (`LoRaPHY` в MATLAB R2024a) на реальном файле
> `14-28-27_436886418Hz_01_Fd1M-kv.pcm` — все 368 символов, 178 байт, CFO, NetID
> и ASCII-баннер идентичны. CRC проходит (43A2).

## Структура (модули)

| Файл | Назначение |
|------|-----------|
| `lora_types.h`         | Общие типы (`cd`, `cvec`) и `mod` в стиле MATLAB |
| `fft.h` / `.cpp`       | БПФ: radix-2 + Bluestein для произвольной длины (`fft_len` не степень 2) |
| `resample.h` / `.cpp`  | Полифазный ресемплинг (`resample`) и ФНЧ (`lowpass`) |
| `gf2.h` / `.cpp`       | GF(2): контрольная сумма PHY-заголовка (матрица 5×12) |
| `hamming.h` / `.cpp`   | Кодирование/декодирование Хэмминга (4/5…4/8) |
| `crc16.h` / `.cpp`     | CRC-16/CCITT (x¹⁶+x¹²+x⁵+1) и `calc_crc` LoRa |
| `whitening.h` / `.cpp` | 255-байтовая последовательность выбеливания |
| `lora_phy.h` / `.cpp`  | Ядро: chirp/dechirp/detect/sync/demodulate/decode + encode/modulate + I/O |
| `main.cpp`             | Консольный интерфейс (интерактив + пакетный CLI-режим) |
| `build.bat`, `CMakeLists.txt` | Сборка |

## Сборка CMake:
```sh
cmake -S . -B build && cmake --build build --config Release
```

## Использование

### Интерактивный режим
Запустите `lora.exe` без аргументов и выбирайте пункт меню:

- **1) Демодуляция и декодирование файла** — программа поочерёдно спросит путь к
  файлу, формат, `Fs`, `BW`, `SF`, `RF`, наличие заголовка, fast-режим и длину
  преамбулы. Enter — принять значение по умолчанию (в квадратных скобках).
- **2) Самопроверка** — сгенерирует сигнал из введённого сообщения и тут же его
  демодулирует/декодирует (проверка полного тракта).

Пример параметров для тестового файла: `Fs=1e6`, `BW=125e3`, `SF=8`,
`RF=438e6`, заголовок — да, fast — нет, преамбула — 6.

### Пакетный режим (CLI)
```
lora rx <файл> <pcm|cfile> <Fs> <BW> <SF> <RF> <hdr 0|1> <fast 0|1> <преамбула>
```
Пример:
```
lora.exe rx 14-28-27_436886418Hz_01_Fd1M-kv.pcm pcm 1e6 125e3 8 438e6 1 0 6
```
Выводит символы, байты и ASCII в машиночитаемом виде (удобно для проверки).

## Форматы файлов сигнала

- **`pcm`** — сырой interleaved **int16** I/Q (I,Q,I,Q…), нормировка `/32768`.
  Это формат из `vsop2.m` (`fread(..., 'int16')`).
- **`cfile`** — interleaved **float32** I/Q (формат GNU Radio), как в
  `LoRaPHY.read` / `load_signal_from_file.m`.

## Параметры (свойства `LoRaPHY`)

`rf_freq`, `sf` (7…12), `bw`, `fs`, `has_header` (1 — явный заголовок),
`cr`, `crc`, `preamble_len`, `fast_mode` (пропуск ФНЧ),
`zero_padding_ratio` (по умолчанию 10). В режиме явного заголовка `cr`, `crc` и
`payload_len` берутся из PHY-заголовка автоматически.
